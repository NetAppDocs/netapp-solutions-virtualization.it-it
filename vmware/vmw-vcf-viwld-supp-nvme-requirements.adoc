= Requisiti di implementazione per il datastore NVMe/TCP in un workload domain VMware Cloud Foundation
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Esamina la progettazione di rete consigliata e i requisiti di infrastruttura per distribuire un datastore NVMe/TCP in un dominio di carico di lavoro VMware Cloud Foundation. Ti serve un sistema storage ONTAP AFF o ASA completamente configurato, un dominio di gestione VCF distribuito e un dominio di carico di lavoro esistente.



[[infrastructure-requirements]]
== Requisiti infrastrutturali

* Un sistema di archiviazione ONTAP AFF o ASA con porte dati fisiche su switch Ethernet dedicate al traffico di archiviazione.
* La distribuzione del dominio di gestione VCF è completa e il client vSphere è accessibile.
* Un workload domain è già stato distribuito.




[[recommended-nvmetcp-network-design]]
== Progettazione di rete NVMe/TCP consigliata

NetApp consiglia progettazioni di rete completamente ridondanti per NVMe/TCP. Il diagramma seguente illustra un esempio di configurazione ridondante, che garantisce tolleranza agli errori per sistemi di archiviazione, switch, adattatori di rete e sistemi host.

image:vmware-vcf-asa-074.png["Progettazione di rete NVMe-tcp"]

Per il multipathing e il failover su più percorsi, configurare almeno due LIF per nodo di archiviazione in reti Ethernet separate per tutte le SVM nelle configurazioni NVMe/TCP.
