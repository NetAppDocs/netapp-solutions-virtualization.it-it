= Usa un datastore NFS su ONTAP come storage primario per un workload domain VCF
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
In questo caso d'uso, descriviamo la procedura per configurare un datastore NFS su ONTAP come soluzione di storage primario per un workload domain VMware Cloud Foundation (VCF). Questa procedura riassume i componenti necessari, i passaggi di configurazione e il processo di implementazione.



[[benefits-of-nfs]]
== Vantaggi di NFS

*Semplicità e facilità d'uso:* NFS è semplice da configurare e gestire, il che lo rende una scelta eccellente per gli ambienti che richiedono una condivisione dei file rapida e semplice.

*Scalabilità:* l'architettura di ONTAP consente a NFS di scalare in modo efficiente, supportando le crescenti esigenze di dati senza modifiche significative all'infrastruttura.

*Flessibilità:* NFS supporta un'ampia gamma di applicazioni e carichi di lavoro, rendendolo versatile per vari casi d'uso, inclusi gli ambienti virtualizzati.



[[scenario-overview]]
== Panoramica dello scenario

Questo scenario comprende i seguenti passaggi di alto livello:

* Creare una macchina virtuale di archiviazione (SVM) con interfaccia logica (LIF) per NFS straffic
* Verificare la rete per la macchina virtuale di archiviazione ONTAP (SVM) e che sia presente un'interfaccia logica (LIF) per trasportare il traffico NFS.
* Crea una policy di esportazione per consentire agli host vSphere di accedere al volume NFS.
* Creare un volume NFS sul sistema di archiviazione ONTAP .
* Creare un pool di rete per il traffico NFS e vMotion in SDDC Manager.
* Commissiona gli host in vCenter per l'utilizzo in un Workload Domain VCF.
* Distribuisci un Workload Domain VCF in VCF Ops utilizzando un datastore NFS come storage primario.
* Assicurati che l'immagine del cluster includa il NetApp NFS Plug-in per VMware VAAI.



NOTE: Questa soluzione è applicabile alle piattaforme ONTAP che supportano lo storage NFS, inclusi NetApp AFF, AFX e FAS.



[[prerequisites]]
== Prerequisiti

In questo scenario vengono utilizzati i seguenti componenti e configurazioni:

* NetApp AFF, AFX o sistema storage FAS con una macchina virtuale di storage (SVM) configurata per consentire il traffico NFS.
* È stata creata un'interfaccia logica (LIF) sulla rete IP che deve trasportare il traffico NFS ed è associata all'SVM.
* L'implementazione del dominio di gestione VCF è completa e l'interfaccia di VCF Operations Manager è accessibile.
* Almeno 2 host vSphere configurati per la comunicazione sulla rete di gestione VCF.
* Indirizzi IP riservati per il traffico di archiviazione vMotion e NFS sulla VLAN o sul segmento di rete stabilito a tale scopo.



NOTE: Quando distribuisci un dominio di carico di lavoro VCF, VCF convalida la connettività al server NFS. Questo viene fatto utilizzando l'adattatore di gestione sugli host vSphere prima che venga aggiunto qualsiasi adattatore vmkernel aggiuntivo con l'indirizzo IP NFS. Pertanto, è necessario assicurarsi che 1) la rete di gestione sia instradabile verso il server NFS, oppure 2) sia stato aggiunto un LIF per la rete di gestione all'SVM che ospita il volume del datastore NFS, per garantire che la convalida possa procedere.

Per informazioni sulla configurazione dei sistemi di archiviazione ONTAP fare riferimento alink:https://docs.netapp.com/us-en/ontap["Documentazione ONTAP 9"] centro.

Per informazioni sulla configurazione di VCF, fai riferimento a link:https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1.html["Documentazione di VMware Cloud Foundation"].

Per ulteriori informazioni sull'utilizzo di NFS con cluster vSphere, fare riferimento alink:vmw-vvf-overview.html["Guida di riferimento NFS v3 per vSphere 8"] .

[[deployment-steps]]
== Fasi di distribuzione

Per distribuire un Workload Domain VCF con un datastore NFSv3 come storage primario, completa i seguenti passaggi:

.Verifica della rete per ONTAP SVM
[%collapsible%open]
====
Verifica che siano state configurate le interfacce logiche necessarie per la rete che trasporterà il traffico NFS tra il cluster ONTAP e il Workload Domain.

. Da ONTAP System Manager, nel menu a sinistra, vai su *Storage VMs* e fai clic sulla SVM da utilizzare per il traffico NFS. Nella scheda *Overview*, sotto *Network interfaces*, fai clic sul numero sopra l'etichetta *NFS*. Nell'elenco verifica che siano presenti gli indirizzi IP LIF richiesti.
+
image:vmw-vcf-viwld-principal-nfs-001.png["Verifica le LIF NFS per SVM"]



In alternativa, verificare i LIF associati a un SVM dalla CLI ONTAP con il seguente comando:

[source, cli]
----
network interface show -vserver <SVM_NAME>
----
. Verifica che gli host vSphere possano comunicare con il server NFS ONTAP. Accedi all'host vSphere tramite SSH ed esegui il ping della LIF SVM:


[source, cli]
----
vmkping <IP Address>
----

NOTE: Quando distribuisci un Workload Domain, VCF convalida la connettività al server NFS. Questo viene fatto utilizzando l'adattatore di gestione sugli host vSphere prima che venga aggiunto qualsiasi adattatore vmkernel aggiuntivo con l'indirizzo IP NFS. Pertanto, è necessario assicurarsi che 1) la rete di gestione sia instradabile verso il server NFS, oppure 2) sia stato aggiunto un LIF per la rete di gestione all'SVM che ospita il volume del datastore NFS, per garantire che la convalida possa procedere.

====
.Crea criteri di esportazione per la condivisione del volume NFS
[%collapsible%open]
====
Creare una policy di esportazione in ONTAP System Manager per definire il controllo di accesso per i volumi NFS.

. In ONTAP System Manager, fare clic su *Storage VMs* nel menu a sinistra e selezionare una SVM dall'elenco.
. Nella scheda *Impostazioni* individua *Criteri di esportazione* e clicca sulla freccia per accedervi.
+
image:vmw-vcf-viwld-principal-nfs-002.png["Accedi alle politiche di esportazione"]

+
{nbsp}

. Dopo che clicchi su Aggiungi, si aprirà la finestra *Nuova policy di esportazione*. Aggiungi un nome per la policy, clicca sul pulsante *Aggiungi nuove regole* e poi sul pulsante *+Aggiungi* per iniziare ad aggiungere una nuova regola.
+
image:vmw-vcf-viwld-principal-nfs-003.png["Nuova politica di esportazione"]

+
{nbsp}

. Inserisci gli indirizzi IP, l'intervallo di indirizzi IP o la rete che desideri includere nella regola. Deseleziona le caselle *SMB/CIFS* e *FlexCache* e seleziona le opzioni relative ai dettagli di accesso qui sotto. Selezionare le caselle UNIX è sufficiente per l'accesso host vSphere.
+
image:vmw-vcf-viwld-principal-nfs-004.png["Salva nuova regola"]

+

NOTE: Quando distribuisci un Workload Domain, VCF convalida la connettività al server NFS. Questo viene fatto utilizzando l'adattatore di gestione sugli host vSphere prima che venga aggiunto qualsiasi adattatore vmkernel aggiuntivo con l'indirizzo IP NFS. Pertanto, è necessario assicurarsi che la policy di esportazione includa la rete di gestione VCF per consentire la convalida.

. Una volta inserite tutte le regole, fare clic sul pulsante *Salva* per salvare la nuova politica di esportazione.
. In alternativa, è possibile creare criteri e regole di esportazione nella CLI ONTAP .  Fare riferimento ai passaggi per la creazione di una policy di esportazione e l'aggiunta di regole nella documentazione ONTAP .
+
** Utilizzare ONTAP CLI perlink:https://docs.netapp.com/us-en/ontap/nfs-config/create-export-policy-task.html["Creare una politica di esportazione"] .
** Utilizzare ONTAP CLI perlink:https://docs.netapp.com/us-en/ontap/nfs-config/add-rule-export-policy-task.html["Aggiungere una regola a un criterio di esportazione"] .




====
.Crea volume NFS
[%collapsible%open]
====
Creare un volume NFS sul sistema di archiviazione ONTAP da utilizzare come datastore nella distribuzione del dominio del carico di lavoro.

. Da ONTAP System Manager, andare su *Archiviazione > Volumi* nel menu a sinistra e fare clic su *+Aggiungi* per creare un nuovo volume.
+
image:vmw-vcf-viwld-principal-nfs-005.png["Aggiungi nuovo volume"]

+
{nbsp}

. Aggiungere un nome per il volume, specificare la capacità desiderata e selezionare la VM di archiviazione che ospiterà il volume.  Fare clic su *Altre opzioni* per continuare.
+
image:vmw-vcf-viwld-principal-nfs-006.png["Aggiungi dettagli sul volume"]

+
{nbsp}

. In Autorizzazioni di accesso, selezionare la Politica di esportazione che include la rete di gestione VCF o l'indirizzo IP e gli indirizzi IP della rete NFS che verranno utilizzati sia per la convalida del server NFS che per il traffico NFS.
+
image:vmw-vcf-viwld-principal-nfs-007.png["Aggiungi dettagli sul volume"]

+
+ {nbsp}

+

NOTE: Quando distribuisci un dominio di carico di lavoro VCF, VCF convalida la connettività al server NFS. Questo viene fatto utilizzando l'adattatore di gestione sugli host vSphere prima che venga aggiunto qualsiasi adattatore vmkernel aggiuntivo con l'indirizzo IP NFS. Pertanto, è necessario assicurarsi che 1) la rete di gestione sia instradabile verso il server NFS, oppure 2) sia stato aggiunto un LIF per la rete di gestione all'SVM che ospita il volume del datastore NFS, per garantire che la convalida possa procedere.

. In alternativa, puoi creare volumi NFS tramite la CLI di ONTAP. Per ulteriori informazioni, consulta il comando link:https://docs.netapp.com/us-en/ontap-cli/volume-create.html["crea volume"] nella documentazione dei comandi ONTAP.

[[vcf-workload-domain-default-cluster]]
=== VCF Workload Domain - Cluster predefinito

Dopo che il dominio di gestione è attivo e funzionante, puoi creare il dominio di carico di lavoro VCF:

* Utilizzando l'interfaccia utente VCF Ops. Gli host vSphere vengono commissionati in vCenter e il pool di rete viene configurato. Usa System Manager o l'API ONTAP per esportare il volume NFS sugli host vSphere.
* Importa un ambiente vSphere esistente come nuovo dominio di workload. Puoi utilizzare ONTAP tools for VMware vSphere, System Manager o l'API ONTAP per distribuire il datastore NFSv3 o NFS4.1 nel cluster vSphere.




[[vcf-workload-domain-additional-cluster]]
=== VCF Workload Domain - Cluster aggiuntivo

Per espandere il dominio del carico di lavoro con un cluster aggiuntivo, fai riferimento a  https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/building-your-private-cloud-infrastructure/working-with-workload-domains/expand-a-workload-domain/add-a-cluster-to-a-workload-domain-using-the-sddc-manager-ui.html["Aggiungi un cluster SDDC a un dominio VCF"].

A livello generale, i passaggi per aggiungere un cluster aggiuntivo al dominio di carico di lavoro sono i seguenti: * Assicurati che gli host siano stati commissionati e che i pool di rete siano configurati in vCenter. * Il volume NFS è stato predisposto sul sistema storage ONTAP ed esportato sugli host nel cluster aggiuntivo. * Il volume NFS è montato su uno degli host vSphere nel cluster aggiuntivo. * Crea un nuovo cluster SDDC sul dominio di carico di lavoro in vCenter e segui la procedura guidata per aggiungere il cluster aggiuntivo al dominio di carico di lavoro.
