[role="lead"]
In questo caso d'uso, descriviamo la procedura per configurare un cluster stretch per il dominio di gestione VMware Cloud Foundation (VCF) utilizzando ONTAP MetroCluster con FC, iSCSI, NVMe-oF, NFSv3 o NFSv4.1 come datastore primario. VCF offre flessibilità nelle opzioni di implementazione in base alle tue esigenze. Lo strumento VCF Installer viene utilizzato per implementare un nuovo dominio di gestione VCF o per convertire un ambiente vSphere esistente in un dominio di gestione VCF. In questo documento ci concentreremo sulla parte MetroCluster e rimanderemo ad altra documentazione in base alle fasi di implementazione.

image:vmw-vcf-vmsc-mgmt-mcc-001.png["Dominio di gestione VCF con vMSC, larghezza=500"]



[[introduction]]
== Introduzione

In questa soluzione ti mostreremo come implementare un dominio di gestione VCF esteso con ONTAP MetroCluster come Principal Datastore. MetroCluster permette di implementare una soluzione di alta disponibilità per tutti i carichi di lavoro in esecuzione sul cluster ONTAP. Se hai bisogno di implementare una soluzione di alta disponibilità specifica per i carichi di lavoro, considera l'utilizzo di SnapMirror active sync (SAN e NAS). SnapMirror active sync (SAN) opera a livello di consistency group, mentre SnapMirror active sync (NAS) opera a livello di SVM. Per ulteriori informazioni, consulta link:vmw-vcf-vmsc-mgmt-smas.html["Configura un cluster stretch per un dominio di gestione VCF usando SnapMirror Active Sync (SAN e NAS)"].



[[prerequisites]]
== Prerequisiti

Questo scenario richiede i seguenti componenti e configurazioni:

* Configurazione ONTAP MetroCluster supportata
* Macchina virtuale di storage (SVM) configurata con il protocollo storage preferito.
* È stata creata un'interfaccia logica (LIF) per gestire il traffico storage ed è associata all'SVM.

[[deployment-steps-for-greenfield-vcf-management-domain-with-metrocluster]]
== Passaggi di distribuzione per il dominio di gestione VCF Greenfield con MetroCluster

Per le implementazioni Greenfield (nuove implementazioni senza componenti VCF preesistenti), viene utilizzato lo strumento VCF Installer per distribuire il dominio di gestione. In questo scenario sono supportati VMFS su FC e NFSv3.

Nel caso di VMFS su FC, consulta link:vmw-vcf-mgmt-principal-fc.html["Dominio di gestione VCF con datastore VMFS basato su FC su ONTAP come storage principale"] per maggiori informazioni. Per NFSv3, consulta link:vmw-vcf-mgmt-principal-nfs.html["Dominio di gestione VCF con datastore NFSv3 su ONTAP come storage principale"] per maggiori informazioni.



[[deployment-steps-for-brownfield-vcf-management-domain-with-metrocluster]]
== Passaggi di distribuzione per il dominio di gestione VCF Brownfield con MetroCluster

Un'implementazione brownfield è uno scenario in cui hai già un ambiente vSphere esistente e vuoi convertirlo in un dominio di gestione VCF.

Per iSCSI, NVMe-oF e NFSv4.1, devi configurarlo con vCenter (preferibilmente con ONTAP tools) e poi usare lo strumento di installazione VCF per integrarlo nel dominio di gestione. Per maggiori informazioni, consulta link:vmw-vcf-mgmt-vmfs.html["Convergenza di vCenter con il datastore VMFS"] e link:vmw-vcf-mgmt-nfs.html["Convergenza di vCenter con datastore NFS"].
