[role="lead"]
Inizia aggiungendo un datastore iSCSI come storage supplementare per un dominio di gestione VMware Cloud Foundation (VCF). Imposterai una Storage Virtual Machine (SVM) con interfacce logiche (LIF) per iSCSI, configurerai la rete iSCSI sugli host vSphere, distribuirai ONTAP tools for VMware vSphere e creerai un datastore VMFS.

Creare una SVM con più LIF per il traffico iSCSI.

[role="quick-margin-para"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]link:vmw-vcf-mgmt-supplemental-iscsi-storage.html["Configurare l'archiviazione"]
