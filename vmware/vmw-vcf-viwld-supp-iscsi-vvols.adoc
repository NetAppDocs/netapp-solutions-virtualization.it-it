= Flusso di lavoro di deployment per aggiungere un datastore iSCSI vVols come storage supplementare in un workload domain
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Inizia configurando un datastore iSCSI vVols come storage supplementare in un workload domain VMware Cloud Foundation (VCF). Creerai la SVM e le LIF, imposterai la rete iSCSI, distribuirai ONTAP tools for VMware vSphere e configurerai lo storage.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]link:vmw-vcf-viwld-supp-iscsi-vvols-requirements.html["Esaminare i requisiti di distribuzione"]
[role="quick-margin-para"]
Esamina i requisiti per distribuire iSCSI vVols in un workload domain VMware Cloud Foundation.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]link:vmw-vcf-viwld-supp-iscsi-vvols-svm-lifs.html["Creare SVM e LIF"]
[role="quick-margin-para"]
Creare una SVM con più LIF per il traffico iSCSI.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]link:vmw-vcf-viwld-supp-iscsi-vvols-network.html["Configurare la rete"]
[role="quick-margin-para"]
Configura la rete per iSCSI sugli host vSphere.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]link:vmw-vcf-viwld-supp-iscsi-vvols-storage.html["Configurare l'archiviazione"]
[role="quick-margin-para"]
Distribuire e utilizzare gli strumenti ONTAP per configurare l'archiviazione.
