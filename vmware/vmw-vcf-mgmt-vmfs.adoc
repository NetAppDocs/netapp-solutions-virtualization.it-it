= Flusso di lavoro di deployment per la convergenza di istanze server vCenter al dominio di gestione VCF con datastore VMFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Convergi un cluster vSphere esistente con datastore NetApp ONTAP VMFS in un dominio di gestione VMware Cloud Foundation. Rivedrai i requisiti di configurazione, distribuirai gli ONTAP tools e fornirai i datastore VMFS, e userai lo strumento VCF Installer per convalidare e usare i componenti esistenti, distribuire i nuovi componenti necessari e configurare la piattaforma.

Questo flusso di lavoro viene utilizzato anche per sfruttare qualsiasi datastore VMFS supportato da utilizzare come storage primario per il dominio di gestione VCF.

Per una panoramica del processo di conversione, consulta la documentazione VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Conversione dell'infrastruttura virtuale esistente in un VCF"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]link:vmw-vcf-mgmt-vmfs-requirements.html["Rivedere i requisiti di configurazione"]
[role="quick-margin-para"]
Esamina i requisiti principali per la convergenza delle istanze server vCenter ai domini di gestione VCF utilizzando i datastore VMFS.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]link:vmw-vcf-mgmt-vmfs-deploy.html["Distribuisci ONTAP tools e crea un datastore VMFS supportato"]
[role="quick-margin-para"]
Distribuisci ONTAP tools for VMware vSphere e crea un datastore VMFS supportato.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]link:vmw-vcf-mgmt-vmfs-converge.html["Convergi il cluster vSphere nel dominio di gestione VCF"]
[role="quick-margin-para"]
Utilizza lo strumento di installazione VCF per convalidare, riutilizzare i componenti esistenti e distribuire quelli nuovi che costituiscono il dominio di gestione VCF.
