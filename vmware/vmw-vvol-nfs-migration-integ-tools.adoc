= Strumenti di integrazione ONTAP per datastore NFS in ambienti VMware
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Scopri gli strumenti di integrazione ONTAP per gestire, monitorare e proteggere i datastore NFS negli ambienti VMware, tra cui ONTAP tools for VMware vSphere, il plug-in NFS VAAI e SnapCenter Plug-in for VMware vSphere.

NetApp fornisce i seguenti strumenti per gestire e proteggere i datastore NFS negli ambienti VMware:

* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/index.html["ONTAP tools for VMware vSphere"^]*: Integra la gestione di ONTAP nel Client vSphere per il provisioning, il monitoraggio e la gestione dei datastore NFS e applica le impostazioni host ESXi consigliate.
* *link:https://docs.netapp.com/us-en/nfs-plugin-vmware-vaai/index.html["Plug-in NetApp NFS per VMware VAAI"^]*: Trasferisce le operazioni di storage, come la clonazione, su ONTAP, migliorando le prestazioni e riducendo il carico sugli host ESXi.
* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/enable-storage-replication-adapter.html["Storage Replication Adapter (SRA)"^]*: Si integra con VMware Live Site Recovery (precedentemente VMware Site Recovery Manager) per orchestrare il disaster recovery utilizzando la replica ONTAP SnapMirror.
* *link:vmw-dr-gs.html["NetApp Disaster Recovery"]*: Gestisce il disaster recovery delle VM sui datastore NFS dalla NetApp Console.
* *link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/index.html["SnapCenter Plug-in for VMware vSphere"^]*: Fornisce backup e ripristino coerenti con l'arresto anomalo e coerenti con le VM per le VM sui datastore NFS.
* *link:https://docs.netapp.com/us-en/data-infrastructure-insights/index.html["Data Infrastructure Insights NetApp"^]*: Fornisce visibilità sulle prestazioni e sullo stato di salute dello storage ONTAP e dell'infrastruttura VMware.


Questi strumenti semplificano le operazioni, migliorano le prestazioni e garantiscono la protezione dei dati per i datastore NFS negli ambienti VMware.
