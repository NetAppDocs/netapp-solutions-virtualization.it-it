= Flusso di lavoro di distribuzione per la convergenza dell'istanza server vCenter al dominio di gestione VCF con datastore NFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Convergi un cluster vSphere esistente con datastore NFS NetApp ONTAP in un dominio di gestione VMware Cloud Foundation. Rivedrai i requisiti di configurazione, distribuirai gli ONTAP tools e fornirai i datastore NFS, e userai il VCF Installer Tool per convalidare e utilizzare i componenti esistenti, distribuire i nuovi componenti necessari e configurare la piattaforma.

Questo flusso di lavoro è applicabile anche se si intendono utilizzare i datastore ONTAP NFS 4.1 come storage primario per il dominio di gestione VCF.

Per una panoramica del processo di convergenza, consulta la documentazione VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Conversione dell'infrastruttura virtuale esistente in un VCF"].
