= Requisiti di implementazione per l'aggiunta di NFS vVols in un workload domain
:allow-uri-read: 


[role="lead"]
Esamina la progettazione di rete e i requisiti di infrastruttura consigliati per implementare NFS vVols in un dominio di workload VMware Cloud Foundation. Ti serve un sistema storage ONTAP AFF o ASA completamente configurato, un dominio di gestione VCF completato e un dominio di workload esistente.



[[infrastructure-requirements]]
== Requisiti infrastrutturali

Assicurarsi che i seguenti componenti e configurazioni siano presenti.

* Un sistema di archiviazione ONTAP AFF o FAS con porte dati fisiche su switch Ethernet dedicate al traffico di archiviazione.
* La distribuzione del dominio di gestione VCF è completa e il client vSphere è accessibile.
* Un workload domain è già stato distribuito.




[[recommended-nfs-network-design]]
== Progettazione di rete NFS consigliata

Configurare progetti di rete ridondanti per NFS per garantire tolleranza agli errori per sistemi di archiviazione, switch, adattatori di rete e sistemi host.  È comune distribuire NFS con una singola subnet o più subnet, a seconda dei requisiti architettonici.
