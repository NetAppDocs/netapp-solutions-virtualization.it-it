= Scopri Red Hat OpenShift Virtualization
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Red Hat® OpenShift Virtualization consente alle organizzazioni di migrare, eseguire e gestire senza problemi macchine virtuali (VM) tradizionali insieme a carichi di lavoro moderni su una piattaforma applicativa cloud ibrida unificata. OpenShift Virtualization è disponibile come operatore incluso con qualsiasi abbonamento OpenShift. Questo componente aggiuntivo per la OpenShift Container Platform offre una soluzione robusta per integrare le VM con applicazioni containerizzate. Utilizza Kernel-based Virtual Machine (KVM), l'affidabile hypervisor del kernel Linux, noto per prestazioni robuste, scalabilità e stabilità, per offrire virtualizzazione enterprise per le macchine virtuali, come oggetti nativi all'interno di OpenShift.

image:redhat-openshift-044.png["Virtualizzazione OpenShift"]



[[key-features-of-red-hat-openshift-virtualization]]
== Caratteristiche principali di Red Hat OpenShift Virtualization

**Carichi di lavoro ibridi:** Migra ed esegui VM con i vantaggi del cloud nativo, gestendole insieme a container e carichi di lavoro serverless utilizzando un toolset unificato.

**Modernizzazione graduale:** Modernizzati al tuo ritmo adottando container, implementando microservizi o integrando l'intelligenza artificiale, senza interrompere le VM esistenti.

**Integrazione con Kubernetes:** Sfrutta le risorse personalizzate di Kubernetes per aggiungere funzionalità di virtualizzazione al tuo cluster OpenShift.



[[capabilities-of-red-hat-openshift-virtualization]]
== Funzionalità di Red Hat OpenShift Virtualization

**Gestione delle macchine virtuali:** Crea e gestisci sia le macchine virtuali Linux che Windows.

**Carichi di lavoro unificati:** Esegui contemporaneamente carichi di lavoro di pod e VM all'interno di un cluster.

**Connettività:** Accedi alle macchine virtuali tramite varie console e strumenti da riga di comando.

**Operazioni sulle VM:** Importa, clona e migra in tempo reale le VM tra i nodi.

**Gestione delle risorse:** Gestisci le interfacce di rete e i dischi di storage collegati alle VM.



[[compatibility]]
== Compatibilità

Sebbene OpenShift Virtualization differisca concettualmente da VMware vSphere, offre una piattaforma moderna pensata specificamente per gli amministratori di virtualizzazione, con funzionalità familiari come: **Migrazione in tempo reale:** equivalente a vMotion in vSphere.

**Gestione dello storage:** Le classi di storage in OpenShift sono allineate con Storage Policy Based Management (SPBM) in vSphere.

**Storage persistente:** Le Persistent Volume Claim (PVC) e i Persistent Volume (PV) corrispondono ai Datastore in vSphere.
